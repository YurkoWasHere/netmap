# Ubiquiti EdgeRouter (EdgeOS)

An EdgeRouter is added as an **SNMP** device, plus two extra data sources on its **Polling** tab for what EdgeOS
doesn't publish over SNMP. Tested on an EdgeRouter X, EdgeOS v3.0.1.

## 1. SNMP (ports, traffic, addresses, ARP)

```
configure
set service snmp community YOUR-COMMUNITY authorization ro
set service snmp community YOUR-COMMUNITY client <netmap's IP>
commit ; save ; exit
```

In netmap: **Add device → SNMP switch** with the router's LAN IP and the community. In its **Settings** tab set
**Role on the map → Internet gateway** if it's your gateway.

## 2. Client names: EdgeOS web UI (read-only login)

```
configure
set system login user netmap authentication plaintext-password 'A-LONG-RANDOM-PASSWORD'
set system login user netmap level operator
commit ; save ; exit
```

Operator accounts can use the web UI read-only and can't log in over SSH. In netmap: **Polling → Add a data
source → EdgeOS web UI (DHCP names)**, user `netmap` and that password. netmap reads the DHCP leases
(`/api/edge/data.json?data=dhcp_leases`) to name clients.

## 3. Which jack each device is on: MAC table over SSH

EdgeOS shows the switch's MAC table (the `switch0` bridge) only in a shell, and only admin-level accounts get a
shell. So netmap uses an admin account that can't do anything else:

- no usable password (`encrypted-password '!'`);
- one SSH key, generated by netmap (the private half never leaves netmap's database), with
  `command="/config/scripts/netmap-read"`: whatever is asked over SSH, the router runs that read-only script
  ([edgeos-netmap-read.sh](edgeos-netmap-read.sh): `bridge fdb show`, or `brctl showmacs switch0`);
- no port forwarding, agent forwarding, X11 or terminal.

In netmap: **Polling → Add a data source → EdgeOS MAC table (SSH key)**. netmap makes the key and shows the exact
commands to paste on the router (as `ubnt` or another admin); **Setup commands** shows them again later.
`/config/scripts` survives firmware upgrades.

To remove it: `configure ; delete system login user netmap-ssh ; commit ; save` and delete
`/config/scripts/netmap-read`.
